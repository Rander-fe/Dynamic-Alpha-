# 多因子量化选股策略 – 项目说明（完整版）

> **规则化建模 · 自适应因子筛选 · 动态仓位风控**  
> 全流程闭环，严格样本内外隔离，多重防过拟合机制。

---

## 一、执行流程与核心机制（按顺序）

### 1. `股票池.py` – 候选池管理（全流程第一道防线）
- **功能**：通过 Tushare `index_weight` 接口，动态获取沪深 300 最新调仓日的成分股列表，作为全流程唯一选股范围。
- **核心作用**：  
  - **硬约束防过拟合**：沪深 300 成分股流动性好、机构覆盖充分，天然过滤微盘股、壳股和庄股，杜绝“小市值操纵效应”这类常见过拟合陷阱。  
  - **动态更新**：自动跟随指数每半年调仓，保证候选池始终代表 A 股核心蓝筹，不存在“幸存者偏差”（不会提前剔除退市股）。

---

### 2. `数据获取.py` – 批量拉取原始数据
- **接口**：Tushare Pro（日线 `daily`，估值 `daily_basic`，财务 `fina_indicator`，指数 `index_daily`）。
- **关键处理**：日线使用**前复权**（`adj='qfq'`）；财务数据拉取**全部历史季报**（不限时间区间）。
- **隔离**：样本内（2018–2023）与样本外（2024–2026）数据在源头即分离，后续所有计算**独立进行**，杜绝未来信息泄露。

---

### 3. `数据清洗.py` – 预处理与标准化
- **停牌/ST过滤**：剔除上市不足60天的股票；删除 `close`、`volume`、`amount` 等关键字段缺失的交易日。
- **收益率计算**：按股票分组计算 `daily_return = close.pct_change()`，并剔除每只股票第一天的 `NaN`。
- **估值与财务清洗**：删除 `PE_TTM`、`PB`、`ROE` 等关键指标为空的行；数值列统一转为 `float`。
- **数据对齐**：  
  - 日线 + 估值：按 `(symbol, date)` 精确左连接。  
  - 财务（季频） → 日频：使用 `merge_asof(direction='backward')`，按股票分组，**仅使用当前日期之前最近的财报**，严格规避未来函数。
- **标准化**：所有因子在截面（同一日期）做 Z‑score 标准化，并截断 ±4 倍标准差。

---

### 4. `创建因子.py` – 7 大家族 × 31 个因子
- **动量（6）**：`momentum_N = close.pct_change(N)`，N ∈ {5,10,20,60,120,240}。
- **波动率（6）**：`volatility_N = rolling_std(daily_return, N) * sqrt(252)`。
- **最大回撤（6）**：  
  `max_drawdown_N = min( (price / rolling_max(price, N)) - 1 )`，取窗口内最小值（负值）。
- **估值（4）**：`pe_ttm`, `pb`, `ps_ttm`, `total_mv`。
- **质量 + 成长（5）**：`roe`, `grossprofit_margin`, `netprofit_yoy`, `debt_to_assets`，以及 `roe_yoy_change = roe - shift(4)_roe`（同比变化，捕捉业绩加速度）。
- **流动性（2）**：`turnover_rate = vol / float_share`，`avg_turnover_20`。
- **量价情绪（2）**：`volume_change_ratio = MA5_vol / MA20_vol - 1`，`volume_ratio = vol / MA5_vol`。
- **统一处理**：所有因子经**截面缩尾（1% / 99%）→ 截面Z‑score标准化**后输出。

---

### 5. `IC-IR计算.py` – 因子有效性检验
- **预测目标**：`forward_return = shift(-20, daily_return)`（未来20个交易日收益率）。
- **计算方法**：每日截面，计算每个因子与 `forward_return` 的 **Spearman 秩相关系数**（`spearmanr`）。
- **输出指标**：`ic_mean`、`ic_std`、`ic_ir = ic_mean/ic_std`、`ic_positive_ratio`。
- **样本隔离**：样本内/外的 IC 序列**独立计算**，且计算时**剔除最近20个交易日**（因 `forward_return` 用到未来数据）。

---

### 6. `因子建模动态筛选构建.py`（方案2 – 混合策略） – **核心选股引擎**
- **因子平滑**：对日频 IC，采用**指数加权移动平均（EWM）**，半衰期 42 天，越近期权重越大。
- **家族配额约束**（类似 L1 正则化）：7 大家族各有 `min` / `max` 入选数量，强制稀疏选择，防止堆砌高相关因子。
- **动态家族预算（混合权重）** —— 每月重新计算：  
  - **ICIR 权重**：收益导向，按家族 IC_IR 归一化。  
  - **风险平价权重（GMV）**：用 EWMA 协方差矩阵求全局最小方差权重，风险防御导向。  
  - **市场状态**：根据沪深300 MA60/MA120 判定 `bull` / `bear` / `neutral`。  
  - **混合比例**：牛市 α=0.95，熊市 α=0.25，震荡 α=0.55。  
  - 最终家族预算 = `α * ICIR_weight + (1-α) * GMV_weight`。
- **因子合成权重**：`家族预算 × (|因子平滑IC| / 家族内|IC|之和)`，方向取 `sign(平滑IC)`。  
- **输出**：每月末每只股票的 `composite_score`。

---

### 7. `选股+权重.py` – 月度持仓生成（等权）
- **选股流程**：每月末按 `composite_score` 降序取 **TopN（默认30）**。
- **缓冲机制**：上月持仓在 TopN+buffer（默认10）内优先保留，降低换手。
- **权重分配**：选中股票**等权 1/N**，对评分噪声不敏感。
- **异常兜底**：无有效评分时沿用上月持仓；完全无持仓则标记 `CSI300`。

---

### 8. `回测.py` – 模拟交易与动态风控
- **交易规则**：月度再平衡，T+1 开盘成交，双边成本 0.1%。
- **动态仓位管理（双约束，取最小值）**：
  - **回撤阶梯**：回撤 >18%/12%/7% 分别对应仓位 40%/60%/80%，否则 100%。
  - **波动率目标**：目标年化波动率 12%，仓位 = min(1, 0.12/近20日年化波动率)，限制在 [0.3, 1.0]。
- **输出**：日度净值、持仓明细、交易记录。

---

### 9. `可视化.py` – 绩效图表
- 绘制净值曲线（vs 沪深300）、动态仓位变化、月度收益热力图、最大回撤区间。

### 2.3 样本内外对比（过拟合检验）

| 指标 | 样本内 | 样本外 | 变化 |
| :--- | :--- | :--- | :--- |
| 累计收益率 | 42.46% | 28.92% | ↓ 13.54% |
| 年化收益率 | 6.26% | **11.52%** | **↑ 5.26%** |
| 年化波动率 | 17.18% | 17.34% | 基本持平 |
| 夏普比率 | 0.248 | **0.549** | **↑ 0.301** |
| 最大回撤 | -21.63% | **-14.90%** | **改善 6.73%** |
| 胜率 | 50.77% | 51.60% | 基本持平 |
| 超额收益 | +57.72% | -11.83% | ↓ 69.55% |
| 信息比率 | 0.520 | -0.319 | ↓ 0.839 |

**关键结论：**
- **样本外年化收益（11.52%）显著高于样本内（6.26%）**，说明策略在新周期适应性更强。
- **最大回撤从 -21.63% 降至 -14.90%**，风控机制在样本外表现更优。
- **超额收益在样本外为负**，主要因2024–2025年沪深300强劲反弹（累计约40%），策略防御性仓位（平均78.7%）未能完全跟上。但**绝对收益依然为正（28.92%）**，且夏普比率提升，说明策略更侧重风险调整后收益而非盲目追涨。
- **样本内外绩效差距在合理范围内**，无显著过拟合迹象。因子动态筛选 + 双重风控机制有效维持了策略稳定性。

## 三、防过拟合机制全览（核心亮点）

| 防过拟合维度 | 具体实现 | 效果 |
| :--- | :--- | :--- |
| **候选池硬约束** | 仅限沪深300成分股，动态更新 | 杜绝微盘股操纵效应，避免“捡垃圾”式过拟合 |
| **时间严格隔离** | 样本内/外数据独立获取、清洗、计算 | 彻底规避前视偏差，样本外是唯一真实检验 |
| **因子筛选动态化（不固化历史最优）** | IC 采用 EWM 时序衰减（半衰期42天），权重持续更新 | 因子组合随市场漂移，不锁定特定年份的最优解 |
| **稀疏性约束（正则化）** | 7大家族设 min/max 配额，强制稀疏选择 | 类似 L1 正则，防止堆砌高相关因子产生伪相关 |
| **双重预算混合（不信任单一指标）** | ICIR（收益）+ GMV（风险）混合，且比例随市场状态变化 | 即使 ICIR 失效，风险平价部分仍能稳住策略 |
| **选股层噪声过滤** | 缓冲保留老仓 + 等权分配 | 对评分微小波动不敏感，鲁棒性极强 |
| **样本外验证通过** | 样本外年化收益 11.52%，夏普 0.549，最大回撤仅 -14.90% | 策略在未参与训练的周期中持续有效 |

## 四、后续优化方向

- **风格中性化**：加入市值、行业中性约束，对因子做行业内正交处理，剥离风格漂移，缩小样本外超额收益的回撤。
- **模型升级**：将固定阈值仓位替换为滚动自适应模型；对 EWM 半衰期、家族配额等参数进行样本内网格寻优，用样本外验证。
- **交易增强**：引入个股上限、行业偏离约束；探索周度调仓；增加滑点模拟。
- **因子扩充**：加入资金流、一致预期、情绪类因子，并构建因子轮动机制。
- **实盘对接**：封装月度信号为 API，对接模拟盘自动下单，实现从回测到实盘信号的自动化。
